# 从递归入手二维动态规划

## 1.精炼总结

尝试函数有1个可变参数<font color="red">可以完全决定返回值</font>，进而可以改出1维动态规划表的实现

同理

尝试函数有2个可变参数<font color="red">可以完全决定返回值</font>，进而可以改出2维动态规划表的实现



一维、二维、三维甚至多维动态规划问题，大体过程都是:

写出尝试递归

记忆化搜索(从顶到底的动态规划)

严格位置依赖的动态规划(从低到顶的动态规划)

空间、时间的更多优化



动态规划表的大小: <font color="red">每个可变参数的可能性数量相乘</font>

动态规划方法的时间复杂度: <font color="red">动态规划表的大小 * 每个格子的枚举代价</font>



二维动态规划依然需要去整理 <font color="red">动态规划表的格子之间的依赖关系</font>

找寻依赖关系，往往<font color="red">通过画图来建立空间感</font>，使其更显而易见

然后依然是<font color="red">从简单格子填写到复杂格子</font>的过程，即严格位置依赖的动态规划(从低到顶)



二维动态规划的压缩空间技巧原理不难，会了之后千篇一律

但是<font color="red">不同题目的依赖关系不一样</font>，需要 <font color="red">很细心的画图来整理具体题目的依赖关系</font>

最后进行空间压缩

## 2.题目1:最小路径和

代码:

```java
import java.util.Arrays;

//测试链接: https://leetcode.cn/problems/minimum-path-sum/description/
//只能往下或者往右
public class Code01_Minimum_path_sum {

    //1.暴力递归
    public int minPathSum1(int[][] grid) {
        return getMinPath(grid,grid.length-1,grid[0].length-1);
    }
    public static int getMinPath(int[][] grid,int x,int y){
        if(x==0 && y==0){
            return grid[x][y];
        }
        int left = y-1 >= 0 ? getMinPath(grid,x,y-1):Integer.MAX_VALUE;
        int up = x-1 >=0 ? getMinPath(grid,x-1,y):Integer.MAX_VALUE;
        return Math.min(left,up) + grid[x][y];
    }

    //2.暴力递归 + 缓存表
    public int minPathSum2(int[][] grid) {
        int row = grid.length,col = grid[0].length;
        int[][] dp = new int[row][col];
        for(int[] d:dp) Arrays.fill(d,-1);
        return getMinPathWithCache(grid,row-1,col-1,dp);
    }
    public static int getMinPathWithCache(int[][] grid,int x,int y,int[][] dp){
        if(x==0 && y==0){
            return grid[x][y];
        }
        if(dp[x][y] != -1) return dp[x][y];
        int left = y-1 >= 0 ? getMinPathWithCache(grid,x,y-1,dp):Integer.MAX_VALUE;
        int up = x-1 >=0 ? getMinPathWithCache(grid,x-1,y,dp):Integer.MAX_VALUE;
        dp[x][y] = Math.min(left,up) + grid[x][y];
        return dp[x][y];
    }

    //3.从底到顶的动态规划
    public int minPathSum3(int[][] grid) {
        int row = grid.length,col = grid[0].length;
        int[][] dp = new int[row][col];
        dp[0][0] = grid[0][0];
        for(int i=1;i<col;i++){
            dp[0][i] = dp[0][i-1] + grid[0][i];
        }
        for(int i=1;i<row;i++){
            dp[i][0] = dp[i-1][0] + grid[i][0];
        }
        for(int i=1;i<row;i++){
            for(int j=1;j<col;j++){
                dp[i][j] = Math.min(dp[i-1][j],dp[i][j-1]) + grid[i][j];
            }
        }
        return dp[row-1][col-1];
    }

    //4.从底到顶的动态规划,空间压缩
    //依赖左和上，用一维空间去压缩二维空间
    //左边就是左边的，上边的就是当前格子
    public int minPathSum4(int[][] grid) {
        int row = grid.length,col = grid[0].length;
        int[] dp = new int[col];
        dp[0] = grid[0][0];
        for(int i=1;i<col;i++){
            dp[i] = dp[i-1] + grid[0][i];
        }
        for(int i=1;i<row;i++){
            dp[0] = dp[0] + grid[i][0];
            for(int j=1;j<col;j++){
                dp[j] = Math.min(dp[j-1],dp[j]) + grid[i][j];
            }
        }
        return dp[col-1];
    }

}

```

依赖关系很好找，但是这个空间压缩的思路可以学习

## 3.题目2:单词搜索

代码:

```java
//测试链接: https://leetcode.cn/problems/word-search/
public class Code02_Word_search {
    public boolean exist(char[][] board, String word) {
        char[] wordCharArray = word.toCharArray();
        for(int i=0;i<board.length;i++){
            for(int j=0;j<board[0].length;j++){
                if(f(board,i,j,wordCharArray,0)) return true;
            }
        }
        return false;
    }
    public static boolean f(char[][] board,int x,int y,char[] wordArray,int index){
        if(index == wordArray.length){
            return true;
        }
        if(x<0 || y<0 || x>=board.length || y>=board[0].length || board[x][y] != wordArray[index]){
            return false;
        }
        char tmp = board[x][y];
        board[x][y] = 0;//标记为访问过
        boolean ans = f(board,x+1,y,wordArray,index+1)
                || f(board,x,y+1,wordArray,index+1)
                || f(board,x-1,y,wordArray,index+1)
                || f(board,x,y-1,wordArray,index+1);
        board[x][y] = tmp;
        return ans;
    }
}
```

这道题揭示了一个道理，能改成动态规划的递归，统一特征：

<font color="red">决定返回值的可变参数类型往往比较简单，一般不会比int类型更复杂。为什么？</font>



从这个角度，可以<font color="red">解释带路径的递归(可变参数类型复杂)，不适合或者说没有必要改成动态规划</font>，题目2说明这一点



一定要<font color="red">写出可变参数类型简单(不比int类型更复杂)</font>，并且<font color="red">可以完全决定返回值的递归</font>，

保证做到<font color="red">这些可变参数可以完全代表之前决策过程对后续过程的影响！</font>再去改动态规划！
