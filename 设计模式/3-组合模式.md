# 组合模式

## 1.概念

组合模式是一个很简单的设计模型，本质上就是<font color="red">递归</font>+<font color="red">多态</font>

定义：**组合模式**是一种结构型的设计模型，用于将对象组合成树型结构，以表示部分和整体的层次关系。



### 1.1场景

我们先来看一个场景: 如果我们想要实现一个统计各个省份的人口，你要怎么设计？

其实这个东西，我们都明白，类似于“文件夹”一样，一个省份“点开”有多个市,一个市"点开"有多个区，然后每个区有不同的人口数。

这个用图形表达就是:

![](assets\四川省人口统计样例图.png)

这是不是很像一个数据结构——<font color="red">树</font>

没错，所以组合模式基本上都是可以用<font color="red">树</font>这种数据结构去表示。

### 1.1.2 Java代码实现场景

首先，我们会发现，既然是树，那么不论是"省"还是"市"还是"区"，都是一个节点

<font color="red">节点的共性是什么？可以计算人口</font>

所以我们先定义一个`Population`接口

```java
public interface PopulationNode {
    int getPopulation();//获取人口数
}
```

然后呢？区要实现这个接口

```java
//区的类
public class District implements PopulationNode{
    private String name;
    private int populationNum;
    public District(String name,int populationNum){
        this.name = name;
        this.populationNum = populationNum;

    }

    @Override
    public int getPopulation() {
        return populationNum;
    }
}
```

再然后嘞？一个市可以有多个区，我们再实现市的接口

```java
public class City implements PopulationNode{
    private String name;
    private ArrayList<PopulationNode> districts = new ArrayList<>();//存储多个区

    public City(String name){
        this.name = name;
    }
    public void addDistrict(District district){
        districts.add(district);
    }

    @Override
    public int getPopulation() {
        return districts.stream().mapToInt(PopulationNode::getPopulation).sum();
    }
}
```

最后，我们如法炮制实现省的类

```java
public class Province implements PopulationNode{
    private String name;
    private ArrayList<PopulationNode> cities = new ArrayList<>();

    public Province(String name){
        this.name = name;
    }
    public void addDistrict(City city){
        cities.add(city);
    }

    @Override
    public int getPopulation() {
        return cities.stream().mapToInt(PopulationNode::getPopulation).sum();
    }
}

```

所以我们就写好了，测试的Main函数如下:

```java
public class Main {
    public static void main(String[] args) {
        District jinjiang = new District("锦江区", 1200000);
        District qingyang = new District("青羊区", 850000);
        District fucheng = new District("涪城区", 780000);
        District youxian = new District("游仙区", 560000);
        
        City chengdu = new City("成都市");
        chengdu.addDistrict(jinjiang);
        chengdu.addDistrict(qingyang);

        City mianyang = new City("绵阳市");
        mianyang.addDistrict(fucheng);
        mianyang.addDistrict(youxian);
        
        Province sichuan = new Province("四川省");
        sichuan.addDistrict(chengdu);
        sichuan.addDistrict(mianyang);
        
        System.out.println(sichuan.getPopulation());
    }
}

```

我们通过ide的调试发现，确实在程序中就是一颗<font color="red">树</font>
